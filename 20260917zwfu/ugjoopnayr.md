# 生病住院时会“发霉”？这样做可以避免！

> 更新时间：2026-09-17 (UTC+8)

**小科普**

**如何预防院内****真菌感染**

众所周知，食物放久了会发霉，家具、衣物受潮后也容易发霉，那么人在生病住院时会“发霉”吗？

发霉的本质是真菌的生长。真菌作为自然界的一种微生物，广泛存在于土壤、花草树木及各种植物，也存在于各种物体表面，包括你的皮肤表面。**在住院期间，尤其是当你患病或抵抗力低下时，就存在真菌感染的可能。**真菌感染可以从轻度的皮肤感染，也就是常见的皮疹、手足癣，到可危及生命的真菌性肺炎。

**因此，尽可能避免发生真菌感染就显得非常重要。**尽管医护人员会采取各种措施保护你免受真菌感染，但仍有一些情况会增加真菌感染的风险。

**哪些情况容易引发**

**真菌感染？**

**1. 留置中心静脉导管。**住院期间的输液治疗可能需要留置中心静脉导管，真菌可通过静脉导管进入血液，从而导致念珠菌血症的发生。

**2. 创伤。**真菌自然存在于你的皮肤和医护人员的手上，这些真菌可通过伤口、创面进入人体引发感染，尤其当你的创伤较严重时。

**3. 入住重症监护室(ICU)。**在救治过程中你可能会需要使用生命支持设备，这会使真菌感染风险增加，尤其是念珠菌、曲霉菌。

**4. 手术。**手术部位感染除了常见的细菌，也可以是真菌。

**5. 建筑施工。**建造或翻新施工容易扬起空气中的真菌孢子，可能会引起患者的曲霉感染，尤其是对于免疫力较差、病情危重的住院患者。

**住院期间如何保护自己免受真菌感染？**

住院期间，虽然医务人员会采取各种措施保护患者免受真菌感染的风险，但患者的配合会使防控效果事半功倍。****

**1. 了解真菌感染。**真菌感染有不同的类型，早期可能只是浅表的局部粘膜感染（口炎、咽炎、食道炎），了解真菌感染有助于识别早期症状，及时报告给医生，从而避免发展成重症。

**2. 遵医嘱用药。**合理使用抗生素、激素等药物。有些医生可能会处方抗真菌药物来预防真菌感染。

**3. 保持手卫生。**确保每个人在接触你之前进行手卫生，尤其需要提醒你的照护者及探访者。

**4. 保持病房清洁干燥。**保持室内空气流通，避免室内真菌滋生，不要因为觉得被打扰而拒绝保洁员打扫你的房间。

**5. 做好个人生活物品的清洁消毒。**梳子和毛巾都可能带有皮肤真菌菌落片段。定时消毒、更换所穿着的鞋子以避免脚气。

**6. 注意休息和营养。**提高自身的抵抗力是保护自己免受感染的重要基础，充足的休息和充分的营养是前提。

**7. 探视者遵循探视礼仪。**探视者也要遵循感染防控的原则，别让送温暖变成了送感染。

**哪些特殊人群更容易受真菌感染的威胁？**

1. 器官移植患者

2. 造血干细胞移植患者

3. 恶性肿瘤患者

4. 艾滋病感染者

**特殊易感人群出院后如何预防真菌感染？**

1. 避免去**环境脏**的地方，比如建筑工地。

2. 沙尘暴等**空气质量差**的日子避免外出。

3. **远离**鸟类、蝙蝠、家禽。

4. 接触土壤、肥料时佩戴**手套**。

5. 到田园、森林进行户外活动时穿**长袖衣裤**。

6. 清理发霉物品时，保证充足**通风**并佩戴**N95**口罩。

为了让自己在生病住院时不“发霉”，要记得吃好睡好，做好个人卫生和环境卫生，特殊人群做好个人防护，听从医护人员的专业指导哦！
