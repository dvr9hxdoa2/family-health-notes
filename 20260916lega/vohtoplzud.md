# 郑大三附院生殖健康医院建档流程，建议收藏！

> 更新时间：2026-09-16 (UTC+8)

建档是助孕过程中的一个重要环节，如何省时省力的顺利完成这一步骤呢？以下内容请注意查收哦！

**一、建档时机**
夫妻双方化验单齐全后，即可挂号验单，男、女科医生下建病历医嘱后即可建档。 

**二、化验单准备**
1.需要提前复印：

①染色体、血型、心电图、传染病（乙肝丙肝梅毒艾滋）、造影、宫腔镜和女方助孕一览表/母体因素一览表

②热敏纸打印的化验单

2. 复印或拍照：其余化验单可复印或手机拍照留存。

3. 多周期建档，如无新查化验单，复印一份一览表即可。

★**请将双方****所有检查结果****用手机拍照留底以备后期使用，原件将留档保存。**

**三、证件要求**
1. 双方身份证原件

要求：均在有效期内，且有磁能读取（临时身份证无磁）。建档时要在公安系统读取身份证信息

2. 双方结婚证原件

要求：①2本结婚证，姓名、出生日期、身份证号要和身份证件信息一致。

②照片清晰，字迹清晰。

③如丢失或损毁请及时补办。

3.双方户口本原件（供精受卵助孕夫妻需提供）

**五、建档注意事项**
1. 每次人授、取卵建档均需男科医嘱。冻胚移植建档不需要男科医嘱。

2. 第一次建档或上次建档超过一年，需要男女双方都到场，证件齐全。距离上次建档不超过一年，有医嘱可建档。

3. 每次手术时必须男女双方同时到场，证件齐全。

4. 如有特殊情况可到分诊台具体咨询。
